# Когда и как обращаться к советнику

Пользователь может обратиться напрямую. Координатор полного цикла и любая из остальных ролей могут вызвать советника на любом этапе, если выбор существенно меняет контракт, архитектуру, стоимость сопровождения, нагрузку или достоверность проверки. Сначала сформулируй решение одним вопросом. У технического вопроса должны быть реальные последствия для текущей задачи.

| Кто обнаружил развилку | Подходящий повод |
|---|---|
| Аналитик | Два допустимых контракта повторной доставки по-разному влияют на существующих потребителей. Нужно понять технические последствия перед вопросом пользователю. |
| Консилиум разработки | Есть выбор между доработкой действующего хранилища и вторым хранилищем. Отличаются эксплуатационные расходы и гарантии свежести. |
| Ревьюер | Рефакторинг уберёт дублирование, но может связать два модуля с разными контрактами. У обоих подходов есть основания в текущем коде. |
| Тестировщик | Доступный стенд даёт результат, который нельзя перенести на рабочую СУБД. Есть несколько способов получить надёжную проверку с разной стоимостью. |
| Диагност | Причина установлена, однако варианты её устранения по-разному влияют на согласованный контракт. |

**Перед вызовом.** Прочитай уже переданное по задаче мнение советника. Переиспользуй вывод при тех же условиях. Для повторного вызова укажи новый факт, изменённое ограничение или контраргумент и поясни, какую часть вывода он ставит под вопрос. Обычную локальную правку с подходящим аналогом выполняй по правилам своей роли. Ожидания пользователя по продукту уточняй у него.

**Передача.** Вызови отдельного исполнителя по имени `devrelay-python-advisor` или передай ему путь к [инструкции советника](../SKILL.md). Передай вопрос, целевой проект, проверенные места кода или замеры, ограничения, варианты и предыдущий вердикт, если он был. Отметь, что уже утверждено пользователем. Путь к проекту нужен советнику даже при использовании скилла из другого каталога. Если отдельный исполнитель недоступен, применяй эти инструкции сам и явно укажи, кто провёл разбор.

**Возврат.** Значимый новый вывод передай пользователю под заголовком «Мнение технического советника». При делегировании верни его владельцу диалога через вызвавшую роль. Владелец показывает вывод один раз, до принятия затронутого решения. Если вывод меняет утверждённый план, подними вопрос до зависимых правок. Передай тот же вердикт следующим участникам в контексте задачи.
