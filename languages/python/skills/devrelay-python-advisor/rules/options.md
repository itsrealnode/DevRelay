# Как сравнивать технические решения

Определи, что нужно решить сейчас и чем будет измеряться успех. Бери исходные ограничения из постановки, конфигурации, кода и наблюдений. Для каждого важного утверждения отмечай основание. Например, «отчёт запускается каждые десять минут» можно подтвердить расписанием. Утверждение «он тормозит API» требует наблюдения за обеими нагрузками или воспроизводимого замера. Отделяй гипотезу от проверенного факта.

Сравни решения на одном сценарии и при одинаковых условиях. Включи сохранение текущего подхода, если он выполняет задачу. Для каждого реального варианта назови выигрыш, цену внедрения и сопровождения, существенное ограничение и условия выбора. Число вариантов зависит от задачи. Отбрось несовместимый вариант, кратко назвав нарушенное требование.

**Выбор БД для отчёта.** Выясни, какие запросы доминируют, откуда приходят данные, каковы объём и рост, какова допустимая задержка отчёта и кто поддерживает систему. Для второго хранилища учти загрузку истории, доставку изменений и восстановление после отставания. Если основная неопределённость в производительности, предложи сравнить один и тот же отчёт на представительном объёме при обычной нагрузке API. Оцени время отчёта и влияние на API по целям проекта. Укажи, если целевое значение ещё предстоит согласовать. Не приписывай проекту замеры из другого окружения.

**Предложение по коду.** Укажи конкретную точку входа и входные данные, на которых варианты различаются. Для выделения общей операции проверь вызывающие стороны, их права, ошибки и границы транзакций. Назови минимальное изменение и проверку сохранения поведения. Если преимущество можно получить меньшей правкой, включи её в сравнение. Фрагмент кода в ответе уместен, когда уточняет решение.

Если неопределённость определяет выбор, предложи короткий эксперимент. Опиши данные, сравниваемые варианты, наблюдаемый результат и условие пересмотра. Явно различай выполненный замер и предложенный эксперимент. Работа советника заканчивается вердиктом, а решение о внедрении остаётся у владельца задачи.
