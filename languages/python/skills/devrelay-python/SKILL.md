# DevRelay Python · Полный цикл

Ты ведёшь задачу в одном диалоге с пользователем. Передавай работу отдельным исполнителям по [правилам координации](rules/council.md). Если при выборе общего скилла пользователь явно просит только один этап, вызови соответствующую роль, верни её результат и заверши задачу на этом этапе.

1. Передай [аналитику](../devrelay-python-analyst/SKILL.md) исходный запрос и целевой проект для сверки. Если пользователь уже дал актуальную сверку, возьми её за основу. Проверяй заново только изменившиеся или открытые пункты.
2. По [правилам согласования](../devrelay-python-development/rules/approval.md) определи, достаточно ли прямого поручения и действующего контракта. Для небольшой определённой задачи передай [разработчику](../devrelay-python-development/SKILL.md) исходное поручение, рабочий аналог и разрешённые изменения сразу. Если нужен план, поручи подготовить его в режиме чтения и представь пользователю. Явную просьбу дождаться апрува передай всем исполнителям.
3. Проследи за реализацией и самопроверкой в границах прямого поручения либо утверждённого плана. При продолжении задачи используй уже полученный апрув, пока объём и контракт сохраняются.
4. Передай текущие изменения независимому [ревьюеру](../devrelay-python-reviewer/SKILL.md), после ревью и исправлений вызови отдельного [тестировщика](../devrelay-python-tester/SKILL.md). Веди возврат дефектов и финальную проверку по [правилам приёмки](rules/acceptance.md).
5. Верни пользователю результат по исходным требованиям, выводы ревью и фактически запущенные проверки для последней версии, включая то, что осталось открытым.

По симптому с неизвестной причиной можно вызвать [диагноста](../devrelay-python-diagnostician/SKILL.md), а по существенному техническому выбору - [советника](../devrelay-python-advisor/SKILL.md). Подключай их в том месте, где ответ нужен для следующего решения.

При изменении условий запуска или выкладки возьми заключение [DevOps](../devrelay-python-devops/SKILL.md) у аналитика либо вызови роль сам, если этап аналитики пропущен. Включи необходимые действия и открытые вопросы по окружению в план. При ревью подключай роль впервые или повторно, если diff выявил новую зависимость или изменил прежние условия. В итог вынеси оставшееся действие для выкладки и способ его проверить.

Если пользователь просит показать сценарий или выбор в сложной задаче зависит от порядка действий, перехода состояний либо границы между компонентами, подключи [диаграммщика](../devrelay-python-diagrammer/SKILL.md). Передай конкретный вопрос, источники и статус решения. Включи схему и пояснение в сообщение с анализом или планом до его согласования. Используй актуальную схему от аналитика или разработчика. Если реализация изменила путь, обнови затронутый фрагмент.
