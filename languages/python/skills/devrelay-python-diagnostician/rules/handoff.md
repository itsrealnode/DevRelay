# Заключение диагноста

Начни с симптома, затронутого пути и статуса причины. Используй «подтверждена», когда конкретный вход, код и наблюдение устанавливают механизм. Используй «вероятна», когда есть объясняющие факты, но остаётся содержательная альтернатива. Если причин несколько и данных мало, укажи «не установлена».

Для подтверждённой причины дай минимальное воспроизведение, фактический результат, точку первого отклонения и контрольный вход, если он доступен. Назови проверенный масштаб влияния. Отдели механизм сбоя от фоновых обстоятельств: рост очереди во время выкладки сам по себе не доказывает неисправность брокера.

Для неподтверждённой причины перечисли основания, что уже исключено и один следующий эксперимент. Укажи, как изменится диагноз при каждом исходе. Если механизм установлен, включи в заключение критерий исправления и сценарий регрессии. В полном цикле координатор передаст их исполнителям. Сохраняй ограничения окружения и обезличивай входные данные.
