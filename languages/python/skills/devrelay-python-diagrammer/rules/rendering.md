# Как показать схему

| Вопрос | Что показать |
|---|---|
| Когда возвращается ответ, кто фиксирует запись, где возникает повтор? | Диаграмму последовательности (`sequenceDiagram`). Сообщения подписывай действиями. Для альтернатив указывай условие, а для независимых действий избегай ложной гарантии порядка. |
| Как объект переходит между состояниями? | Диаграмму состояний (`stateDiagram-v2`). На стрелке укажи событие или условие. Повтор может оставить состояние прежним или вернуть объект в ранее пройденное состояние. |
| Какие компоненты связаны и что пересекает их границы? | Схему компонентов, в Mermaid обычно `flowchart TD`. Подпиши направление и смысл связи. Добавляй детали инфраструктуры только при наличии источника. |
| Как устроены типы и где важно наследование или владение? | Диаграмму классов (`classDiagram`). Включи только классы и отношения, которые объясняют решение. |

**В чате.** По умолчанию верни отрисовываемый блок `mermaid`. Для строгой UML-нотации или проекта с PlantUML используй соответствующий исходник. Одна схема отвечает на один вопрос. Для длинного маршрута выбери существенный фрагмент или вертикальную компоновку. Подробные имена файлов, длинные условия и объяснение результата вынеси из рисунка.

**Для тикета или документации.** Если нужен файл, создай запрошенный SVG или PNG. Используй локальный рендерер проекта. Для Mermaid CLI команды ниже берут один и тот же исходник. Создай только нужные форматы.

```sh
mmdc -i flow.mmd -o flow.svg
mmdc -i flow.mmd -o flow.png -s 2
```

Для PlantUML аналогично доступны `plantuml -tsvg flow.puml` и `plantuml -tpng flow.puml`. Если рендерера нотации нет, для отдельной картинки можно сделать точную схему в SVG и получить PNG из этого же SVG установленным локальным конвертером. При явно запрошенном экспорте существующего исходника сохрани его единственным источником и сообщи о недоступном формате, если конвертация невозможна.

Открой готовую картинку. Проверь кириллицу, читаемость стрелок, выход текста за границы и совпадение ветвей с исходником. Если нужна свободная иллюстрация для презентации, генератор изображений подходит для оформления. Точные переходы, имена и подписи бери из технической схемы.
