# Технические справочники DevRelay Python

Выбери правило по решению, которое требуется принять или проверить. Открывай справочник применимого стека. Версии библиотек и местные соглашения бери из целевого проекта.

Пример кода выбирай для конкретной части задачи, когда в проекте нет подходящего аналога этой части. Открой примеры своего стека: [Django и DRF](django/examples/README.md) или [FastAPI](fastapi/examples/README.md).

Рекомендации справочника применяй в границах поручения. Сначала установи, какое поведение пользователь просит изменить и на что уже рассчитывают потребители. В остальном сохрани действующий контракт, включая входы, результат и ошибки. Например, use case над готовым `list()` возвращает тот же полный список. Аналогично, если хранилище возвращает `None` при отсутствии записи, сохрани этот результат и в новой обёртке, когда таков её контракт.

При ревью проверь и риски, на которые указывает справочник. Если рекомендация выявила нарушение требования, укажи вход и последствие. Если она предлагает самостоятельное улучшение за пределами задачи, обозначь его отдельно при наличии конкретной пользы. Такое предложение само по себе не требует правки и не блокирует приёмку.
