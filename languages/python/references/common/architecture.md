# Где живёт решение

Проследи один вызов от входа до записи. Сопоставь роли с именами, уже принятыми в проекте. Например, функция `register_ticket()` в `tickets/services.py` уже может выполнять прикладной сценарий целиком.

| Ответственность | Кому поручить | Как проверить |
|---|---|---|
| Разобрать внешний формат и вернуть ответ вызывающей стороне | Маршруту, обработчику сообщения или команде | Один и тот же сценарий вызывается без HTTP и брокера. |
| Координировать действие и связанные изменения | Use case или существующей функции прикладного сервиса | При регистрации заявки сбой записи её истории откатывает обе записи. |
| Вычислить бизнес-правило из значений | Существующему владельцу правила или доменной функции, если правило объединяет несколько понятий | При пятидневке с 09:00 до 17:00 два рабочих часа с пятницы 16:00 заканчиваются в понедельник 10:00, если нет праздников. Такой тест не требует БД. |
| Получить данные или условно изменить запись | Существующему механизму хранения: ORM, менеджеру, репозиторию | Проверь результат запроса на рабочем типе БД и убедись, что внешний откат отменяет запись. |
| Вызвать внешний API и разобрать ответ провайдера | Интеграционному адаптеру | Подмени ответ провайдера. Решение, можно ли продолжать операцию при его недоступности, проверь в сценарии. |

Сохраняй одну точку входа для одной бизнес-операции. Если предполагаемый сервис только передаёт аргументы в репозиторий, вызови подходящий существующий метод напрямую. Выделяй отдельную входную команду, когда у неё свои поля, значения по умолчанию, семантика отсутствующих значений или потребители.

Перед добавлением слоя назови потребителя и решение, за которое этот слой отвечает. Приведи обычный вызов, вход, результат, ошибки и владельца транзакции. Сверь их с ближайшим аналогом, проверь декораторы, регистрацию зависимостей и внешние вызовы интерфейса. Даже короткий метод может обеспечивать права или стабильный контракт. Если единственному внутреннему потребителю достаточно существующего интерфейса чтения, передай его напрямую. При упрощении проверь тот же результат, права доступа и откат.
