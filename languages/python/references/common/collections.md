# Ограничение выборки и загрузка связей

Сначала проверь сигнатуру хранилища, тип результата и ожидания потребителей. Если задача добавляет use case над существующим `storage.list() -> list[Dto]`, сохрани аргументы вызова, тип, полный состав, порядок и область видимости результата. Проверь пустой список, несколько различимых элементов и передачу ошибки согласно контракту. Параметры `limit/offset`, молчаливое усечение и обёртка страницы меняют поведение. Выноси такое изменение на согласование, когда для него есть основание.

Если контракт предусматривает страницу, зафиксируй порядок, фильтр видимости, размер и допустимый максимум. Ограничь запрос в хранилище до материализации. Например, для уже отфильтрованного и упорядоченного Django QuerySet выражение `list(qs[:50])` возвращает до 50 строк из БД. При `list(qs)[:50]` приложение сначала загружает весь результат. Фильтр по владельцу не гарантирует верхней границы количества записей.

Выбери загрузку связей под фактическое чтение. Для имени владельца заявки подойдёт запрос со связью; для коллекции дочерних объектов может быть уместен второй пакетный запрос по ключам выбранной страницы. Сохраняй основной объект, даже когда его необязательная связь пуста, если таков контракт. Проверь также свойства, фильтры внутри сериализатора и агрегаты в цикле: они могут снова обращаться к БД. Для Django см. [варианты загрузки в ORM](../django/orm.md).

Для проверки возьми одну и несколько записей с разными связанными объектами, а для постраничного контракта также набор больше размера страницы. При одинаковых условиях сравни состав и порядок ответа, повторяющиеся SQL-запросы и число строк, переданных приложению. Замер должен охватывать вычисление результата и сериализацию. Один запрос может загрузить всю таблицу. Два запроса на страницу могут быть корректной пакетной загрузкой. Различай число доставленных строк и количество строк, просмотренных самой СУБД.

Если по контракту нужны все данные, проследи границу потребления памяти до записи результата: итерация порциями в БД бесполезна, если затем весь CSV накапливается в списке. Для небольшого справочника с фиксированной верхней границей укажи, откуда известна эта граница. Не вводи произвольную отсечку, которая потеряет часть результата.
