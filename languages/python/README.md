# DevRelay для Python

Начни с общего скилла [DevRelay](../../skills/devrelay/SKILL.md) или передай задачу напрямую [координатору Python](skills/devrelay-python/SKILL.md). Для отдельного этапа выбери соответствующую роль.

| Роль | Когда вызывать |
|---|---|
| [Координатор](skills/devrelay-python/SKILL.md) | Провести задачу через полный цикл |
| [Аналитик](skills/devrelay-python-analyst/SKILL.md) | Сверить требования с кодом и уточнить критерии |
| [Разработчик](skills/devrelay-python-development/SKILL.md) | Подготовить план или реализовать согласованную задачу |
| [Ревьюер](skills/devrelay-python-reviewer/SKILL.md) | Проверить текущий diff или PR |
| [Тестировщик](skills/devrelay-python-tester/SKILL.md) | Проверить операцию по требованиям и воспроизвести сбой |
| [Советник](skills/devrelay-python-advisor/SKILL.md) | Сравнить варианты технического решения |
| [Диагност](skills/devrelay-python-diagnostician/SKILL.md) | Проследить сбой и установить причину |
| [DevOps](skills/devrelay-python-devops/SKILL.md) | Выяснить требования к запуску и выкладке |
| [Диаграммщик](skills/devrelay-python-diagrammer/SKILL.md) | Показать последовательность действий или переходы состояний |

У каждой роли есть свой `SKILL.md` и правила этапа. Общие соглашения и примеры по Django и FastAPI собраны в [справочнике](references/index.md). Постоянные сценарии для проверки отдельных ролей и полного цикла описаны в [evals](evals/README.md).
